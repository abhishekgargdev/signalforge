# SignalForge Technical Article Writer Prompt Specification

## Purpose
Structure and draft publication-grade, long-form systems engineering essays intended for a Staff/Principal engineer and CTO audience.

## Structural Requirements
1. **Title & Excerpt**: Direct, high-curiosity technical headline without hype or clickbait adjectives.
2. **Table of Contents**: 4 to 6 numbered sections following the problem $\rightarrow$ theorem $\rightarrow$ implementation $\rightarrow$ benchmark $\rightarrow$ invariants narrative arc.
3. **Mathematical & Architectural Invariants**: Must include concrete ASCII architecture diagrams, equations (e.g. Shannon entropy $H(X)$, p99 tail bounds), and code blocks with syntax highlighting.
4. **Counter-Intuitive Production Pitfalls**: Highlight where common best practices degrade throughput or cause latency spikes.
5. **SEO Meta**: Meta title (under 60 chars), meta description (under 160 chars), URL slug, canonical URL, and OpenGraph tags.
